Tailwind CSS v3.4 Documentation

Tailwind CSS is a utility-first CSS framework packed with classes like flex, pt-4, and text-center that can be composed to build any design, directly in your markup.

Zero CSS Overhead

Never write custom CSS selectors again for standard user interfaces.

Fully Responsive

Build complex layouts directly using built-in breakpoint modifiers.

Customizable

Configure theme variables inline or extend default color palettes.

Fast CDN Integration (v3.4)

The Play CDN is perfect for rapid prototyping, interactive documentation, and light projects. It includes all v3.4 features out-of-the-box without requiring a build step.

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <!-- Tailwind CSS v3.4 Play CDN Script -->
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          colors: {
            brand: '#0ea5e9',
          }
        }
      }
    }
  </script>
</head>
<body class="bg-slate-900 text-white flex items-center justify-center h-screen">
  <h1 class="text-3xl font-bold text-brand">Hello Tailwind v3.4!</h1>
</body>
</html>

Key Highlights in Tailwind CSS 3.4

:has() Variant Parent Selection Based on Children

Style a parent element based on its descendants using the new has-* variant.

<div class="has-[:checked]:bg-brand-900/50 p-4 border rounded">
  <input type="checkbox" /> Toggle selection
</div>

h-dvh / h-svh Dynamic Viewport Units

Avoid mobile browser URL bar jumping with real dynamic viewport height classes (h-dvh, h-svh, h-lvh).

<main class="min-h-dvh flex flex-col"> ... </main>

text-balance Balanced Headlines

Automatically balance typography across wrapping lines without ugly orphans.

<h1 class="text-4xl font-bold text-balance">Eye-Catching Layouts Made Simple</h1>
